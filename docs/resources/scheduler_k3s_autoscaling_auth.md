# dokku_scheduler_k3s_autoscaling_auth (Resource)

Manages KEDA TriggerAuthentication metadata grouped under a single trigger for a dokku application or globally

### Requirements

- Dokku >= 0.38.31

### Export support

Partial - trigger authentication metadata values are secrets, so they are written to the companion vars-file.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `metadata`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `trigger`. Fields left empty are omitted from the address. Manages the whole `metadata` collection; entries are identified by their key.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Set AWS secret manager trigger metadata on an app
resource "dokku_scheduler_k3s_autoscaling_auth" "example" {
  app     = dokku_app.node_js_app.app
  trigger = "aws-secret-manager"
  metadata = {
    awsRegion  = "us-east-1"
    secretName = "my-secret"
  }
}

# Set a global trigger authentication shared across apps
resource "dokku_scheduler_k3s_autoscaling_auth" "example_2" {
  global  = true
  trigger = "aws-secret-manager"
  metadata = {
    awsRegion = "us-east-1"
    roleArn   = "arn:aws:iam::123456789012:role/keda"
  }
}
```
