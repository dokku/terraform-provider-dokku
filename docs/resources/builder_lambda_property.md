# dokku_builder_lambda_property (Resource)

Manages the builder-lambda configuration for a given dokku application

### Requirements

- Dokku >= 0.38.8

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `value`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `property`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

### Properties

`property` accepts one of the following, applied with `dokku builder-lambda:set`. A property with no form in a scope is rejected there, matching dokku's own rejection.

| Property | Scopes | Report key (app) | Report key (global) |
| --- | --- | --- | --- |
| `lambdayml-path` | app, global | `lambdayml-path` | `global-lambdayml-path` |

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Setting the lambda.yml path for an app
resource "dokku_builder_lambda_property" "example" {
  app      = dokku_app.node_js_app.app
  property = "lambdayml-path"
  value    = "config/lambda.yml"
}

# Setting the lambda.yml path globally
resource "dokku_builder_lambda_property" "example_2" {
  global   = true
  property = "lambdayml-path"
  value    = "lambda.yml"
}
```
