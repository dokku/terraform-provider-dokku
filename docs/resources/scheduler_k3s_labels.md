# dokku_scheduler_k3s_labels (Resource)

Manages scheduler-k3s labels scoped to a (process_type, resource_type) pair for a dokku application or globally

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `labels`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, `process_type`, and `resource_type`. Fields left empty are omitted from the address. Manages the whole `labels` collection; entries are identified by their key.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Set deployment labels on an app's web process
resource "dokku_scheduler_k3s_labels" "example" {
  app           = dokku_app.node_js_app.app
  process_type  = "web"
  resource_type = "deployment"
  labels = {
    "app.kubernetes.io/component" = "api"
    tier                          = "edge"
  }
}

# Set ingress labels on an app at the global process scope
resource "dokku_scheduler_k3s_labels" "example_2" {
  app           = dokku_app.node_js_app.app
  resource_type = "ingress"
  labels = {
    team = "platform"
  }
}

# Set a global deployment label across all apps
resource "dokku_scheduler_k3s_labels" "example_3" {
  global        = true
  resource_type = "deployment"
  labels = {
    managed-by = "docket"
  }
}
```

## Schema

### Required

- `resource_type` (String) Kubernetes resource type to scope the labels to (e.g. deployment, ingress).

### Optional

- `app` (String) Name of the app
- `global` (Boolean) Flag indicating if the labels should be applied globally
- `labels` (Map of String) Map of label key to value to apply at the scope. Under state 'set' a key must not contain '=', and an empty value is stored rather than clearing the key.
- `process_type` (String) Process type to scope the labels to. Defaults to the global process type when empty.

### Read-Only

- `id` (String) The resource's identity address, such as `dokku_scheduler_k3s_labels[app=api]`.
