# dokku_resource_reserve (Resource)

Manages the resource reservations for a given dokku application

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `resources` and `clear_before`, so a teardown resets them. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app` and `process_type`. Fields left empty are omitted from the address. Manages the whole `resources` collection; entries are identified by their key.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_app" "hello_world" {
  app = "hello-world"
}

# Set CPU and memory reservations
resource "dokku_resource_reserve" "example" {
  app = dokku_app.hello_world.app
  resources = {
    cpu    = "100"
    memory = "256"
  }
}

# Set memory reservation for web process type
resource "dokku_resource_reserve" "example_2" {
  app          = dokku_app.hello_world.app
  process_type = "web"
  resources = {
    memory = "512"
  }
}
```
