# dokku_maintenance_custom_page (Resource)

Installs or removes a custom maintenance page for a dokku application.

### Requirements

- Dokku >= 0.38.31
- dokku-maintenance plugin >= 0.10.2

### Runner requirements

- `tarball` is read from the machine running docket, not the dokku server, so the file must exist there even when docket drives the server over `--host`.

### Export support

Partial - export reads the current page back via maintenance:custom-page-export and inlines maintenance.html as content. Multi-file tarball pages collapse to that single content field, so extra assets are not captured. On an older dokku-maintenance without the export command the content cannot be read back and is lifted into a required content input the user supplies before apply.

### Probe support

Partial - the page checksum is probed when the plugin reports it; plugin versions that do not report it make the page plan as drift on every run.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `content` and `tarball`, so a teardown resets them. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- `content` must not be set together with `tarball`.
- At least one of `content` or `tarball` must be set.

## Example Usage

```terraform
resource "dokku_plugin" "maintenance" {
  name = "maintenance"
  url  = "https://github.com/dokku/dokku-maintenance.git"
}

resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Set a custom maintenance page from inline HTML
resource "dokku_maintenance_custom_page" "example" {
  app        = dokku_app.node_js_app.app
  content    = "<html><body><h1>Down for maintenance</h1></body></html>\n"
  depends_on = [dokku_plugin.maintenance]
}
```
