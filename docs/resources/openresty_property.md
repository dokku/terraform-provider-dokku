# dokku_openresty_property (Resource)

Manages the openresty configuration for a given dokku application

### Requirements

- Dokku >= 0.38.9

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `value`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `property`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Setting the proxy read timeout for an app
resource "dokku_openresty_property" "example" {
  app      = dokku_app.node_js_app.app
  property = "proxy-read-timeout"
  value    = "120s"
}

# Setting the client max body size for an app
resource "dokku_openresty_property" "example_2" {
  app      = dokku_app.node_js_app.app
  property = "client-max-body-size"
  value    = "50m"
}

# Setting a global openresty property
resource "dokku_openresty_property" "example_3" {
  global   = true
  property = "bind-address-ipv4"
  value    = "0.0.0.0"
}
```
