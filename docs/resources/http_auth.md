# dokku_http_auth (Resource)

Manages HTTP authentication for a given dokku application

### Requirements

- Dokku >= 0.38.31
- dokku-http-auth plugin >= 0.14.0

### Export support

Partial - the enabled state is exported; the seeded credentials are not carried on this task and come back as dokku_http_auth_user htpasswd hashes.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- `username` and `password` must be set together or not at all.

## Example Usage

```terraform
resource "dokku_plugin" "http_auth" {
  name = "http-auth"
  url  = "https://github.com/dokku/dokku-http-auth.git"
}

resource "dokku_app" "hello_world" {
  app = "hello-world"
}

# Enable HTTP authentication for an app
resource "dokku_http_auth" "example" {
  app        = dokku_app.hello_world.app
  username   = "admin"
  password   = "secret"
  depends_on = [dokku_plugin.http_auth]
}
```
