# dokku_git_sync (Resource)

Syncs a git repository to a dokku application

> **Imperative:** this task runs an operation rather than declaring a resource. It has nothing to undo, so it offers no `absent` or `clear` state.

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Partial - dokku records the resolved commit as `<remote>#<sha>`, which cannot be compared against a branch or tag name, so only the remote and the persisted deploy branch are probed.

### Lifecycle

Applied with state `present` and has no teardown state, so tearing it down leaves the server unchanged. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`.

### Objects

- The app named by `app`. Can restart or redeploy it when `build` or `build_if_changes` is true.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_app" "hello_world" {
  app = "hello-world"
}

# Sync a git repository to an app
resource "dokku_git_sync" "example" {
  app                = dokku_app.hello_world.app
  remote             = "https://github.com/dokku/smoke-test-app.git"
  build              = false
  build_if_changes   = false
  skip_deploy_branch = false
}
```

## Schema

### Required

- `app` (String) Name of the app
- `remote` (String) Git remote url to sync

### Optional

- `build` (Boolean) Trigger an application build after syncing (applied only, not read back)
- `build_if_changes` (Boolean) Trigger a build only if changes are detected (applied only, not read back)
- `git_ref` (String) Git reference to sync
- `skip_deploy_branch` (Boolean) Skip automatically setting the deploy-branch property (applied only, not read back)

- `id` (String) The resource's identity address, such as `dokku_git_sync[app=api]`.
