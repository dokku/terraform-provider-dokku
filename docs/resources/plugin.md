# dokku_plugin (Resource)

Installs or uninstalls a third-party dokku plugin. Installation is a root-level operation, so this task must run over the SSH transport (where dokku wraps privilege server-side) or as root locally. Idempotency is by plugin name only - a changed `url` or `committish` on an already-installed plugin is not detected.

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `name`.

## Example Usage

```terraform
# Install a plugin from a git URL
resource "dokku_plugin" "example" {
  name = "redis"
  url  = "https://github.com/dokku/dokku-redis.git"
}

# Install a plugin pinned to a committish
resource "dokku_plugin" "example_2" {
  name       = "letsencrypt"
  url        = "https://github.com/dokku/dokku-letsencrypt.git"
  committish = "0.25.0"
}
```
