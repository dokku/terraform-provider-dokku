# dokku_service_link (Resource)

Links or unlinks a dokku service to an app

### Requirements

- Dokku >= 0.38.31
- a dokku datastore service plugin >= 2.0.0 matching the service type (e.g. dokku-postgres, dokku-redis, dokku-mysql)

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `service`, and `name`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`. Can restart or redeploy it.
- The datastore service named by `service` and `name`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "redis" {
  name = "redis"
  url  = "https://github.com/dokku/dokku-redis.git"
}

resource "dokku_app" "my_app" {
  app = "my-app"
}

resource "dokku_service_create" "redis_my_redis" {
  service    = "redis"
  name       = "my-redis"
  depends_on = [dokku_plugin.redis]
}

resource "dokku_git_from_image" "my_app_git_from_image" {
  app   = dokku_app.my_app.app
  image = "dokku/smoke-test-app:dockerfile"
}

# Link a redis service named my-redis to my-app
resource "dokku_service_link" "example" {
  app        = dokku_app.my_app.app
  service    = dokku_service_create.redis_my_redis.service
  name       = dokku_service_create.redis_my_redis.name
  depends_on = [dokku_plugin.redis, dokku_git_from_image.my_app_git_from_image]
}

resource "dokku_plugin" "postgres" {
  name = "postgres"
  url  = "https://github.com/dokku/dokku-postgres.git"
}

resource "dokku_service_create" "postgres_my_db" {
  service    = "postgres"
  name       = "my-db"
  depends_on = [dokku_plugin.postgres]
}

# Link a postgres service named my-db to my-app
resource "dokku_service_link" "example_2" {
  app        = dokku_app.my_app.app
  service    = dokku_service_create.postgres_my_db.service
  name       = dokku_service_create.postgres_my_db.name
  depends_on = [dokku_plugin.postgres, dokku_git_from_image.my_app_git_from_image]
}
```
