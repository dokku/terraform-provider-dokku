# dokku_service_create (Resource)

Creates or destroys a dokku service

### Requirements

- Dokku >= 0.38.31
- a dokku datastore service plugin >= 2.3.1 matching the service type (dokku-datastore 0.7.1, e.g. dokku-postgres, dokku-redis, dokku-mysql)

### Export support

Partial - the service, the image it is running and its create-time options are exported; password and root_password are applied only at create and cannot be read back, so they must be re-supplied.

### Probe support

Partial - the service's existence is probed, along with the image it is running and every create-time option the recipe declares; password and root_password are applied only at create and cannot be read back, so they are not drift-detected.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `image`, `image_version`, `config_options`, `custom_env`, `memory`, `shm_size`, `initial_network`, `post_create_network`, `post_start_network`, `password`, `root_password`, `image_drift`, and `restart_apps`, so a teardown resets them. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `service` and `name`. Fields left empty are omitted from the address.

### Objects

- The datastore service named by `service` and `name`. Creates it. Can restart or redeploy it.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "redis" {
  name = "redis"
  url  = "https://github.com/dokku/dokku-redis.git"
}

# Create a redis service named my-redis
resource "dokku_service_create" "example" {
  service    = "redis"
  name       = "my-redis"
  depends_on = [dokku_plugin.redis]
}

resource "dokku_plugin" "postgres" {
  name = "postgres"
  url  = "https://github.com/dokku/dokku-postgres.git"
}

# Create a postgres service named my-db
resource "dokku_service_create" "example_2" {
  service    = "postgres"
  name       = "my-db"
  depends_on = [dokku_plugin.postgres]
}

# Create a redis service on a pinned image
resource "dokku_service_create" "example_3" {
  service       = "redis"
  name          = "my-pinned-redis"
  image         = "redis"
  image_version = "7.2.5"
  depends_on    = [dokku_plugin.redis]
}

# Reconcile a changed image pin by upgrading the service
resource "dokku_service_create" "example_4" {
  service       = "redis"
  name          = "my-upgraded-redis"
  image         = "redis"
  image_version = "7.2.5"
  image_drift   = "upgrade"
  depends_on    = [dokku_plugin.redis]
}

# Reconcile a changed shared memory size with set, stop and start
resource "dokku_service_create" "example_5" {
  service     = "redis"
  name        = "my-tuned-redis"
  shm_size    = "128m"
  image_drift = "upgrade"
  depends_on  = [dokku_plugin.redis]
}
```

## Schema

### Required

- `name` (String) Name of the service instance
- `service` (String) Type of service to create (e.g. redis, postgres, mysql)

### Optional

- `config_options` (String) Extra arguments to pass to the container create command. Applied when the service is created; image_drift decides what happens when an existing service has a different value.
- `custom_env` (Map of String, Sensitive) Map of environment variables to start the service with. Applied when the service is created; image_drift decides what happens when an existing service has a different value. (sensitive)
- `image` (String) Image to start the service with, e.g. postgis/postgis. Applied when the service is created; image_drift decides what happens when an existing service is running something else.
- `image_drift` (String) What to do when the service already exists on an image other than the one pinned, or with a create-time option other than the one declared: 'ignore' it, 'warn' and leave it alone, 'error' out, or 'upgrade' the service to reconcile it. An image is reconciled with <service>:upgrade, which recreates the container with no data migration across major versions; any other option with <service>:set followed by a stop and a start. Both mean downtime. Options the recipe does not declare are left as the server has them. (applied only, not read back)
- `image_version` (String) Image tag to start the service with. Applied when the service is created; image_drift decides what happens when an existing service is running something else.
- `initial_network` (String) Network to attach the service to initially. Applied when the service is created; image_drift decides what happens when an existing service has a different value.
- `memory` (Number) Container memory limit in megabytes. Applied when the service is created; image_drift decides what happens when an existing service has a different value.
- `password` (String, Sensitive) Override the user-level service password. Applied only when the service is created. (not returned when reading state) (sensitive)
- `post_create_network` (List of String) Networks to attach the service container to after creation. Applied when the service is created; image_drift decides what happens when an existing service has a different value. (order is significant)
- `post_start_network` (List of String) Networks to attach the service container to after start. Applied when the service is created; image_drift decides what happens when an existing service has a different value. (order is significant)
- `restart_apps` (Boolean) Restart the apps linked to the service after an image_drift 'upgrade' runs <service>:upgrade, so they reconnect to the new container. Only valid with image_drift 'upgrade', and only acted on when the image drifted and the service has linked apps: reconciling the other options with a stop and a start leaves linked apps alone. (applied only, not read back)
- `root_password` (String, Sensitive) Override the root-level service password. Applied only when the service is created. (not returned when reading state) (sensitive)
- `shm_size` (String) Shared memory size for the service container. Applied when the service is created; image_drift decides what happens when an existing service has a different value.

### Read-Only

- `id` (String) The resource's identity address, such as `dokku_service_create[app=api]`.
