# dokku_apps_property (Resource)

Manages the apps plugin configuration for a given dokku application or globally

### Requirements

- Dokku >= 0.38.12

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `value`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `property`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

### Properties

`property` accepts one of the following, applied with `dokku apps:set`. A property with no form in a scope is rejected there, matching dokku's own rejection.

| Property | Scopes | Report key (app) | Report key (global) |
| --- | --- | --- | --- |
| `deploy-source` | app | `deploy-source` |  |
| `deploy-source-metadata` | app | `deploy-source-metadata` |  |
| `disable-autocreation` | global |  | `global-disable-autocreation` |

## Example Usage

```terraform
# Disabling app auto-creation globally
resource "dokku_apps_property" "example" {
  global   = true
  property = "disable-autocreation"
  value    = "true"
}

resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Overriding the deploy-source for an app
resource "dokku_apps_property" "example_2" {
  app      = dokku_app.node_js_app.app
  property = "deploy-source"
  value    = "git"
}

# Overriding the deploy-source-metadata for an app
resource "dokku_apps_property" "example_3" {
  app      = dokku_app.node_js_app.app
  property = "deploy-source-metadata"
  value    = "https://example.com/repo"
}
```
