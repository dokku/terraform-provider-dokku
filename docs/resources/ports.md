# dokku_ports (Resource)

Manages the ports for a given dokku application

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `port_mappings`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`. Manages the whole `port_mappings` collection; entries are identified by `scheme` and `host`.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Map http port 80 to container port 5000
resource "dokku_ports" "example" {
  app = dokku_app.node_js_app.app
  port_mappings = [{
    container = 5000
    host      = 80
    scheme    = "http"
  }]
}
```
