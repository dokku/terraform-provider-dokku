# dokku_scheduler_docker_local_property (Resource)

Manages the scheduler-docker-local configuration for a given dokku application

### Requirements

- Dokku >= 0.38.8

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `value`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `property`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

### Properties

`property` accepts one of the following, applied with `dokku scheduler-docker-local:set`. A property with no form in a scope is rejected there, matching dokku's own rejection.

| Property | Scopes | Report key (app) | Report key (global) |
| --- | --- | --- | --- |
| `init-process` | app, global | `init-process` | `global-init-process` |
| `parallel-schedule-count` | app, global | `parallel-schedule-count` | `global-parallel-schedule-count` |

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Enabling the init process for an app
resource "dokku_scheduler_docker_local_property" "example" {
  app      = dokku_app.node_js_app.app
  property = "init-process"
  value    = "true"
}

# Setting the parallel schedule count for an app
resource "dokku_scheduler_docker_local_property" "example_2" {
  app      = dokku_app.node_js_app.app
  property = "parallel-schedule-count"
  value    = "4"
}

# Setting the parallel schedule count globally
resource "dokku_scheduler_docker_local_property" "example_3" {
  global   = true
  property = "parallel-schedule-count"
  value    = "4"
}
```
