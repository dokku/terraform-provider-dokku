# dokku_acl_service (Resource)

Manages the dokku-acl access list for a dokku service

### Requirements

- Dokku >= 0.38.31
- dokku-acl plugin >= 2.0.1

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `users`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `service` and `type`. Fields left empty are omitted from the address. Manages the whole `users` collection; entries are identified by value.

### Objects

- The datastore service named by `type` and `service`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "acl" {
  name = "acl"
  url  = "https://github.com/dokku-community/dokku-acl.git"
}

resource "dokku_plugin" "redis" {
  name = "redis"
  url  = "https://github.com/dokku/dokku-redis.git"
}

resource "dokku_service_create" "redis_my_redis" {
  service    = "redis"
  name       = "my-redis"
  depends_on = [dokku_plugin.redis]
}

# Grant users access to a redis service
resource "dokku_acl_service" "example" {
  service    = dokku_service_create.redis_my_redis.name
  type       = dokku_service_create.redis_my_redis.service
  users      = ["alice", "bob"]
  depends_on = [dokku_plugin.acl, dokku_plugin.redis]
}
```
