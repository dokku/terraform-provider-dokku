# dokku_git_auth (Resource)

Manages netrc credentials for a git host

### Requirements

- Dokku >= 0.38.31

### Export support

Not supported - netrc credentials are write-only and cannot be read back.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `host`.

## Example Usage

```terraform
# Configure netrc credentials for a git host
resource "dokku_git_auth" "example" {
  host     = "github.com"
  username = "deploy-bot"
  password = "ghp_examplepat"
}
```
