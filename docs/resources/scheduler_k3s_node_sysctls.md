# dokku_scheduler_k3s_node_sysctls (Resource)

Manages the scheduler-k3s node-level kernel sysctls for unprofiled nodes or a single node profile

### Requirements

- Dokku >= 0.38.30

### Export support

Partial - the global scope and every node profile storing sysctls are exported; a profile whose name dokku cannot derive a node-sysctls helm release from - longer than 26 characters, or carrying uppercase - is reported as a warning and left out, since dokku refuses to write sysctls for it and emitting it would make the whole recipe fail docket validate.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `sysctls`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `global` and `profile`. Fields left empty are omitted from the address. Manages the whole `sysctls` collection; entries are identified by their key.

### Constraints

- Exactly one of `global` or `profile` must be set.

## Example Usage

```terraform
# Set node sysctls for every unprofiled node
resource "dokku_scheduler_k3s_node_sysctls" "example" {
  global = true
  sysctls = {
    "vm.max_map_count" = "262144"
    "vm.swappiness"    = "10"
  }
}

resource "dokku_scheduler_k3s_profile" "edge_workers" {
  name = "edge-workers"
  role = "worker"
}

# Replace the node sysctls of a node profile
resource "dokku_scheduler_k3s_node_sysctls" "example_2" {
  profile = "edge-workers"
  sysctls = {
    "vm.swappiness" = "60"
  }
  depends_on = [dokku_scheduler_k3s_profile.edge_workers]
}
```

## Schema

### Optional

- `global` (Boolean) Scope the sysctls to every node without a node profile.
- `profile` (String) Name of the node profile to scope the sysctls to. The profile must already exist, and dokku only scopes sysctls to a lowercase name of at most 26 characters. A profile's nodes still inherit every global sysctl the profile does not set itself; this task manages only the profile's own map.
- `sysctls` (Map of String) Map of sysctl name to value to apply to the scope. Removing a sysctl stops it being applied to new nodes but does not revert it on nodes already carrying it until they reboot. Under state 'present' a value must not begin with '-', which dokku's flag parser would read as a flag; state 'set' has no such limit.

### Read-Only

- `id` (String) The resource's identity address, such as `dokku_scheduler_k3s_node_sysctls[app=api]`.
