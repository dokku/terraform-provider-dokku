# dokku_git_from_archive (Resource)

Deploys a git repository from an archive URL

> **Imperative:** this task runs an operation rather than declaring a resource. It has nothing to undo, so it offers no `absent` or `clear` state.

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Partial - the recorded archive source is probed; the archive contents are not hashed, so a changed archive at the same url plans as in sync.

### Lifecycle

Applied with state `deployed` and has no teardown state, so tearing it down leaves the server unchanged. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`.

### Objects

- The app named by `app`. Can restart or redeploy it.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- `git_username` and `git_email` must be set together or not at all.

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Deploy a tar.gz archive
resource "dokku_git_from_archive" "example" {
  app          = dokku_app.node_js_app.app
  archive_url  = "https://github.com/dokku/smoke-test-app/archive/refs/heads/master.tar.gz"
  archive_type = "tar.gz"
}
```
