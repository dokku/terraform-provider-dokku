# dokku_service_property (Resource)

Manages a property for a given dokku service

### Requirements

- Dokku >= 0.38.31
- a dokku datastore service plugin >= 2.3.1 matching the service type (dokku-datastore 0.7.1, e.g. dokku-postgres, dokku-redis, dokku-mysql)

### Export support

Partial - every property set on a service is exported except the ones another task owns (the networks, config-options, custom-env, memory and shm-size belong to dokku_service_create; the backup schedule, bucket, IAM flag, region, signature version, endpoint and credentials to dokku_service_backup); the backup credentials are reported only as fingerprints, so they must be re-supplied.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `value`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `service`, `name`, and `property`. Fields left empty are omitted from the address.

### Objects

- The datastore service named by `service` and `name`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "postgres" {
  name = "postgres"
  url  = "https://github.com/dokku/dokku-postgres.git"
}

resource "dokku_service_create" "postgres_my_db" {
  service    = "postgres"
  name       = "my-db"
  depends_on = [dokku_plugin.postgres]
}

# Set the restart-policy for a postgres service
resource "dokku_service_property" "example" {
  service    = dokku_service_create.postgres_my_db.service
  name       = dokku_service_create.postgres_my_db.name
  property   = "restart-policy"
  value      = "always"
  depends_on = [dokku_plugin.postgres]
}

# Publish an exposed postgres service directly rather than through an ambassador
resource "dokku_service_property" "example_2" {
  service    = dokku_service_create.postgres_my_db.service
  name       = dokku_service_create.postgres_my_db.name
  property   = "expose-mode"
  value      = "direct"
  depends_on = [dokku_plugin.postgres]
}
```

## Schema

### Required

- `name` (String) Name of the service instance
- `property` (String) Name of the property to set. Which properties a service accepts depends on its datastore - the backup settings only on one that can be backed up, for example - and <service>:set refuses the rest when the task applies.
- `service` (String) Type of service to configure (e.g. redis, postgres, mysql)
- `value` (String) Value to set the property to. Masked in output for the backup credentials and custom-env. (required)

### Read-Only

- `id` (String) The resource's identity address, such as `dokku_service_property[app=api]`.
