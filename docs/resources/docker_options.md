# dokku_docker_options (Resource)

Manages docker-options for a given dokku application

### Requirements

- Dokku >= 0.38.22

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `phase`, `process_type`, and `option`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Mount the docker socket at deploy
resource "dokku_docker_options" "example" {
  app    = dokku_app.node_js_app.app
  phase  = "deploy"
  option = "-v /var/run/docker.sock:/var/run/docker.sock"
}

# Scope a deploy option to the web process type
resource "dokku_docker_options" "example_2" {
  app          = dokku_app.node_js_app.app
  phase        = "deploy"
  process_type = "web"
  option       = "--memory=512m"
}
```

## Schema

### Required

- `app` (String) Name of the app
- `option` (String) Docker option string (e.g. '-v /var/run/docker.sock:/var/run/docker.sock')
- `phase` (String) Deployment phase the option applies to

### Optional

- `process_type` (String) Process type the option is scoped to (deploy phase only). Empty applies to the default scope (every container).

### Read-Only

- `id` (String) The resource's identity address, such as `dokku_docker_options[app=api]`.
