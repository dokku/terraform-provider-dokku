# dokku_git_property (Resource)

Manages the git configuration for a given dokku application

### Requirements

- Dokku >= 0.38.9

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `value`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `property`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

### Properties

`property` accepts one of the following, applied with `dokku git:set`. A property with no form in a scope is rejected there, matching dokku's own rejection.

| Property | Scopes | Report key (app) | Report key (global) |
| --- | --- | --- | --- |
| `archive-max-files` | global |  | `global-archive-max-files` |
| `archive-max-size` | global |  | `global-archive-max-size` |
| `deploy-branch` | app, global | `deploy-branch` | `global-deploy-branch` |
| `keep-git-dir` | app, global | `keep-git-dir` | `global-keep-git-dir` |
| `rev-env-var` | app | `rev-env-var` |  |
| `source-image` | app | `source-image` |  |

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Setting the deploy branch for an app
resource "dokku_git_property" "example" {
  app      = dokku_app.node_js_app.app
  property = "deploy-branch"
  value    = "main"
}

# Keeping the .git directory during builds
resource "dokku_git_property" "example_2" {
  app      = dokku_app.node_js_app.app
  property = "keep-git-dir"
  value    = "true"
}

# Setting the rev env var for an app
resource "dokku_git_property" "example_3" {
  app      = dokku_app.node_js_app.app
  property = "rev-env-var"
  value    = "GIT_REV"
}
```
