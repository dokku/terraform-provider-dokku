# dokku_registry_property (Resource)

Manages the registry configuration for a given dokku application

### Requirements

- Dokku >= 0.38.8

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `value`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `property`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

### Properties

`property` accepts one of the following, applied with `dokku registry:set`. A property with no form in a scope is rejected there, matching dokku's own rejection.

| Property | Scopes | Report key (app) | Report key (global) |
| --- | --- | --- | --- |
| `image-repo` | app | `image-repo` |  |
| `image-repo-template` | app, global | `image-repo-template` | `global-image-repo-template` |
| `push-extra-tags` | app, global | `push-extra-tags` | `global-push-extra-tags` |
| `push-on-release` | app, global | `push-on-release` | `global-push-on-release` |
| `server` | app, global | `server` | `global-server` |

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Setting the image repo for an app
resource "dokku_registry_property" "example" {
  app      = dokku_app.node_js_app.app
  property = "image-repo"
  value    = "registry.example.com/node-js-app"
}

# Enabling push-on-release for an app
resource "dokku_registry_property" "example_2" {
  app      = dokku_app.node_js_app.app
  property = "push-on-release"
  value    = "true"
}

# Setting the registry server globally
resource "dokku_registry_property" "example_3" {
  global   = true
  property = "server"
  value    = "registry.example.com"
}
```
