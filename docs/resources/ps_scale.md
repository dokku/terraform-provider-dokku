# dokku_ps_scale (Resource)

Manages the process scale for a given dokku application

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `scale`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`. Manages the whole `scale` collection; entries are identified by their key.

### Objects

- The app named by `app`. Can restart or redeploy it unless `skip_deploy` is true.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_app" "hello_world" {
  app = "hello-world"
}

# Scale web and worker processes
resource "dokku_ps_scale" "example" {
  app = dokku_app.hello_world.app
  scale = {
    web    = 2
    worker = 1
  }
}
```
