# dokku_registry_auth (Resource)

Manages docker registry authentication for a dokku application or globally

### Requirements

- Dokku >= 0.38.29

### Export support

Partial - registry:report names the servers a credential exists for, so the logins a server needs are reconstructed; the username and password behind each one are not readable and are lifted into required inputs the caller supplies before apply.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `server`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Log in to a registry for an app
resource "dokku_registry_auth" "example" {
  app      = dokku_app.node_js_app.app
  server   = "ghcr.io"
  username = "deploy-bot"
  password = "ghp_examplepat"
}

# Log in to a registry globally
resource "dokku_registry_auth" "example_2" {
  global   = true
  server   = "docker.io"
  username = "deploy-bot"
  password = "examplepassword"
}
```
