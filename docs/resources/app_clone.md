# dokku_app_clone (Resource)

Clones an existing dokku app to a new app

> **Imperative:** this task runs an operation rather than declaring a resource. It has nothing to undo, so it offers no `absent` or `clear` state.

### Requirements

- Dokku >= 0.38.31

### Export support

Not supported - an imperative clone operation, not reconstructable state.

### Probe support

Partial - only the target app's existence is probed; the clone source and the cloned contents are never read back.

### Lifecycle

Applied with state `present` and has no teardown state, so tearing it down leaves the server unchanged. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`.

### Objects

- The app named by `app`. Creates it. Can restart or redeploy it unless `skip_deploy` is true.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

resource "dokku_git_from_image" "node_js_app_git_from_image" {
  app   = dokku_app.node_js_app.app
  image = "dokku/smoke-test-app:dockerfile"
}

# Clone an app
resource "dokku_app_clone" "example" {
  app        = "node-js-app-staging"
  source_app = "node-js-app"
  depends_on = [dokku_app.node_js_app, dokku_git_from_image.node_js_app_git_from_image]
}
```
