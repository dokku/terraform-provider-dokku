# dokku_maintenance (Resource)

Enables or disables maintenance mode for a given dokku application

### Requirements

- Dokku >= 0.38.31
- dokku-maintenance plugin >= 0.10.2

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "maintenance" {
  name = "maintenance"
  url  = "https://github.com/dokku/dokku-maintenance.git"
}

resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Enable maintenance mode for an app
resource "dokku_maintenance" "example" {
  app        = dokku_app.node_js_app.app
  depends_on = [dokku_plugin.maintenance]
}
```
