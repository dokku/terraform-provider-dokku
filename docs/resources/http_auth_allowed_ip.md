# dokku_http_auth_allowed_ip (Resource)

Manages the set of IP addresses allowed to bypass HTTP auth for a dokku application

### Requirements

- Dokku >= 0.38.31
- dokku-http-auth plugin >= 0.14.0

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `allowed_ips`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`. Manages the whole `allowed_ips` collection; entries are identified by value.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "http_auth" {
  name = "http-auth"
  url  = "https://github.com/dokku/dokku-http-auth.git"
}

resource "dokku_app" "hello_world" {
  app = "hello-world"
}

resource "dokku_http_auth" "hello_world_http_auth" {
  app        = dokku_app.hello_world.app
  depends_on = [dokku_plugin.http_auth]
}

# Allow IP addresses to bypass HTTP auth for an app
resource "dokku_http_auth_allowed_ip" "example" {
  app         = dokku_app.hello_world.app
  allowed_ips = ["192.0.2.1", "198.51.100.0/24"]
  depends_on  = [dokku_plugin.http_auth, dokku_http_auth.hello_world_http_auth]
}
```
