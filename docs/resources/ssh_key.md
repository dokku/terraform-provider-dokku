# dokku_ssh_key (Resource)

Manages an SSH public key for git push access via dokku's ssh-keys plugin

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `name`.

## Example Usage

```terraform
# Add a deploy key
resource "dokku_ssh_key" "example" {
  name = "deploy-bot"
  key  = "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAINioKrRalhe/VF8s43pjp8jpl6LGwv6tF0F5FvKPjUer deploy-bot"
}
```
