# dokku_scheduler_k3s_chart (Resource)

Manages helm chart value overrides for a dokku scheduler-k3s bundled chart

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `values`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `chart`. Manages the whole `values` collection; entries are identified by their key.

## Example Usage

```terraform
# Set chart values via a flat map of dotted paths
resource "dokku_scheduler_k3s_chart" "example" {
  chart = "ingress-nginx"
  values = {
    "controller.replicaCount"         = "3"
    "controller.resources.limits.cpu" = "200m"
  }
}

# Mix nested and flat; nested dotted leaves are escaped for Helm
resource "dokku_scheduler_k3s_chart" "example_2" {
  chart = "traefik"
  values = {
    "ports.web.redirectTo.port" = "websecure"
    service = {
      annotations = {
        "service.beta.kubernetes.io/aws-load-balancer-type" = "nlb"
      }
    }
  }
}
```

## Schema

### Required

- `chart` (String) Name of the helm chart whose values to set (validated by dokku against its bundled HelmCharts list).

### Optional

- `values` (Dynamic) Helm-style values for the chart. Accepts a flat map of dotted property paths or a nested tree; both coalesce to the same key/value form before being applied. In nested form, literal dots in a key segment are escaped to \. so they reach Helm as a single annotation/label key.

### Read-Only

- `id` (String) The resource's identity address, such as `dokku_scheduler_k3s_chart[app=api]`.
