# dokku_storage_ensure (Resource)

Ensures the storage for a given dokku application

> **Deprecated:** use dokku_storage_entry instead; dokku's storage:ensure-directory has been deprecated in favor of storage:create

### Requirements

- Dokku >= 0.38.31

### Export support

Not supported - deprecated; storage state is exported via dokku_storage_mount.

### Probe support

Not supported - `storage:ensure-directory` has no read command, so the task plans as drift on every run.

### Lifecycle

Applied with state `present` and has no teardown state, so tearing it down leaves the server unchanged. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Ensure a storage directory owned by the herokuish user
resource "dokku_storage_ensure" "example" {
  app   = dokku_app.node_js_app.app
  chown = "herokuish"
}
```
