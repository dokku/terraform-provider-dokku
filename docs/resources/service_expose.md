# dokku_service_expose (Resource)

Exposes or unexposes a dokku service on host ports

### Requirements

- Dokku >= 0.38.31
- a dokku datastore service plugin >= 2.0.0 matching the service type (e.g. dokku-postgres, dokku-redis, dokku-mysql)

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `ports`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `service` and `name`. Fields left empty are omitted from the address. Manages the whole `ports` collection; entries are identified by value.

### Objects

- The datastore service named by `service` and `name`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "postgres" {
  name = "postgres"
  url  = "https://github.com/dokku/dokku-postgres.git"
}

resource "dokku_service_create" "postgres_my_db" {
  service    = "postgres"
  name       = "my-db"
  depends_on = [dokku_plugin.postgres]
}

# Expose a postgres service named my-db on host port 5432
resource "dokku_service_expose" "example" {
  service    = dokku_service_create.postgres_my_db.service
  name       = dokku_service_create.postgres_my_db.name
  ports      = ["5432"]
  depends_on = [dokku_plugin.postgres]
}

resource "dokku_plugin" "redis" {
  name = "redis"
  url  = "https://github.com/dokku/dokku-redis.git"
}

resource "dokku_service_create" "redis_my_redis" {
  service    = "redis"
  name       = "my-redis"
  depends_on = [dokku_plugin.redis]
}

# Expose a redis service named my-redis on host port 6379
resource "dokku_service_expose" "example_2" {
  service    = dokku_service_create.redis_my_redis.service
  name       = dokku_service_create.redis_my_redis.name
  ports      = ["6379"]
  depends_on = [dokku_plugin.redis]
}
```
