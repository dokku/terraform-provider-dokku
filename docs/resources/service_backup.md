# dokku_service_backup (Resource)

Manages the S3 backup schedule, authentication, and encryption for a dokku service

### Requirements

- Dokku >= 0.38.31
- a dokku datastore service plugin >= 2.3.1 matching the service type (dokku-datastore 0.7.1, e.g. dokku-postgres, dokku-redis, dokku-mysql)

### Export support

Partial - the backup schedule, bucket, and use_iam flag are exported; the AWS credentials and encryption passphrase are reported only as fingerprints, and the region, signature version and endpoint cannot be declared without the credentials, so all of these must be re-supplied before the recipe can back up.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `service` and `name`. Fields left empty are omitted from the address.

### Objects

- The datastore service named by `service` and `name`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- `schedule` and `bucket` must be set together or not at all.
- `aws_access_key_id` and `aws_secret_access_key` must be set together or not at all.
- `aws_default_region` requires `aws_access_key_id` and `aws_secret_access_key`.
- `aws_signature_version` requires `aws_access_key_id`, `aws_secret_access_key` and `aws_default_region`.
- `endpoint_url` requires `aws_access_key_id`, `aws_secret_access_key` and `aws_signature_version`.
- At least one of `schedule`, `aws_access_key_id`, `aws_secret_access_key` or `encryption_passphrase` must be set.

## Example Usage

```terraform
resource "dokku_plugin" "postgres" {
  name = "postgres"
  url  = "https://github.com/dokku/dokku-postgres.git"
}

resource "dokku_service_create" "postgres_my_db" {
  service    = "postgres"
  name       = "my-db"
  depends_on = [dokku_plugin.postgres]
}

# Schedule daily backups of a postgres service to S3
resource "dokku_service_backup" "example" {
  service               = dokku_service_create.postgres_my_db.service
  name                  = dokku_service_create.postgres_my_db.name
  schedule              = "0 3 * * *"
  bucket                = "my-backup-bucket"
  aws_access_key_id     = "AKIAEXAMPLE"
  aws_secret_access_key = "examplesecret"
  aws_default_region    = "us-east-1"
  encryption_passphrase = "correct-horse-battery-staple"
  depends_on            = [dokku_plugin.postgres]
}
```

- `service` (String) Type of service to back up (e.g. redis, postgres, mysql)

### Optional

- `aws_access_key_id` (String) AWS access key id for backup auth (not returned when reading state)
- `aws_default_region` (String) AWS region used for backup auth
- `aws_secret_access_key` (String, Sensitive) AWS secret access key for backup auth (not returned when reading state) (sensitive)
- `aws_signature_version` (String) AWS signature version used for backup auth
- `bucket` (String) S3 bucket backups are written to
- `encryption_passphrase` (String, Sensitive) Passphrase used to encrypt future backups (not returned when reading state) (sensitive)
- `endpoint_url` (String) S3-compatible endpoint url used for backup auth
- `schedule` (String) Cron schedule for backups
- `use_iam` (Boolean) Use the instance IAM profile instead of static credentials
