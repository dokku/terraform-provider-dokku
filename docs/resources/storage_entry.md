# dokku_storage_entry (Resource)

Creates or destroys a named storage registry entry

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported - every attribute is compared against what storage:list-entries records for the entry, which is the recorded chown and mode rather than the host directory's ownership and permissions on disk; a directory chowned or chmodded out of band is not detected.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `path`, `size`, `access_mode`, `storage_class`, `namespace`, `chown`, `mode`, `reclaim_policy`, `annotations`, and `labels`, so a teardown resets them. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `name`.

## Example Usage

```terraform
# Create a docker-local storage entry owned by the herokuish user
resource "dokku_storage_entry" "example" {
  name  = "node-js-app-data"
  chown = "herokuish"
}
```

## Schema

### Required

- `name` (String) Name of the storage entry

### Optional

- `access_mode` (String) Volume access mode (k3s scheduler; rejected on docker-local). Cannot be changed on an entry that exists, since kubernetes cannot rebind a bound claim; a recipe that disagrees with the recorded value is reported as an error
- `annotations` (Map of String) Map of annotations set on the underlying volume (k3s scheduler). Converged one key at a time on an entry that exists, so a key the recipe omits is left alone
- `chown` (String) Ownership applied to the entry's host directory: an ownership preset or a numeric uid (0-65535). dokku sets the owner and the group to the same id, and refuses the value unless the entry sits at its default host path. Converged on an entry that exists, which re-runs the chown on a docker-local directory
- `labels` (Map of String) Map of labels set on the underlying volume (k3s scheduler). Converged one key at a time on an entry that exists, so a key the recipe omits is left alone
- `mode` (String) Octal permissions applied to the entry's host directory: a 3 or 4 digit mode, recorded in its 4 digit form so 755 and 0755 are the same value (docker-local scheduler; rejected on k3s). dokku refuses the value unless the entry sits at its default host path, and applies it non-recursively. Converged on an entry that exists, which re-runs the chmod on a docker-local directory. Omit it to leave the directory at the 0755 dokku creates it with
- `namespace` (String) Namespace (scheduler-dependent). Converged on an entry that exists
- `path` (String) Host path for the entry: an absolute path, or a docker named volume on docker-local. Defaults to the dokku storage root joined with the entry name. Cannot be changed on an entry that exists; a recipe that disagrees with the recorded path is reported as an error
- `reclaim_policy` (String) Reclaim policy applied to the underlying volume (k3s scheduler). Converged on an entry that exists
- `scheduler` (String) Scheduler that backs the entry. Cannot be changed on an entry that exists; a recipe that disagrees with the recorded scheduler is reported as an error
- `size` (String) Volume size (k3s scheduler; required there and rejected on docker-local). Converged on an entry that exists
- `storage_class` (String) Storage class name (k3s scheduler; rejected on docker-local, and mutually exclusive with path). Cannot be changed on an entry that exists; a recipe that disagrees with the recorded value is reported as an error
