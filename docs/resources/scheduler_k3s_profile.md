# dokku_scheduler_k3s_profile (Resource)

Manages a global scheduler-k3s node profile used when joining nodes to a cluster

### Requirements

- Dokku >= 0.38.31

### Export support

Partial - every profile dokku reports is exported; a profile whose name dokku accepted but the task refuses for state 'present' - longer than 26 characters, or carrying uppercase, so helm cannot release the derived `dokku-node-sysctls-profile-<name>` - is reported as a warning and left out, since emitting it would make the whole recipe fail docket validate. Remove such a profile with a hand-written task using state 'absent'.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `name`.

## Example Usage

```terraform
# Define a worker profile with kubelet args
resource "dokku_scheduler_k3s_profile" "example" {
  name         = "edge-pool"
  role         = "worker"
  kubelet_args = ["max-pods=64", "eviction-hard=memory.available<5%"]
}

# Define a tainted server profile that accepts unknown hosts
resource "dokku_scheduler_k3s_profile" "example_2" {
  name                = "control-plane"
  role                = "server"
  taint_scheduling    = true
  allow_unknown_hosts = true
}
```

## Schema

### Required

- `name` (String) Name of the node profile. Creating one requires a lowercase name of at most 26 characters: dokku prepends dokku-node-sysctls-profile- to it to name the profile's node-sysctls helm release, and helm caps a release name at 53 characters.
- `role` (String) Role for nodes joined with this profile.

### Optional

- `allow_unknown_hosts` (Boolean) Whether to allow ssh connections to nodes whose host key is not yet trusted.
- `kubelet_args` (Set of String) List of key=value kubelet arguments to forward to k3s. (no duplicates)
- `taint_scheduling` (Boolean) Whether to taint the node so only workloads that tolerate the taint schedule on it.

### Read-Only

- `id` (String) The resource's identity address, such as `dokku_scheduler_k3s_profile[app=api]`.

## Import

terraform import dokku_scheduler_k3s_profile.example 'dokku_scheduler_k3s_profile[name=edge-pool]'
