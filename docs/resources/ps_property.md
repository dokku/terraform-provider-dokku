# dokku_ps_property (Resource)

Manages the ps configuration for a given dokku application

### Requirements

- Dokku >= 0.38.9

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`, which refuses `value`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`, `global`, and `property`. Fields left empty are omitted from the address.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

### Properties

`property` accepts one of the following, applied with `dokku ps:set`. A property with no form in a scope is rejected there, matching dokku's own rejection.

| Property | Scopes | Report key (app) | Report key (global) |
| --- | --- | --- | --- |
| `dockerfile-start-cmd` | app | `dockerfile-start-cmd` |  |
| `procfile-path` | app, global | `procfile-path` | `global-procfile-path` |
| `restart-policy` | app, global | `restart-policy` | `global-restart-policy` |
| `skip-deploy` | app, global | `skip-deploy` | `global-skip-deploy` |
| `start-cmd` | app | `start-cmd` |  |
| `stop-timeout-seconds` | app, global | `stop-timeout-seconds` | `global-stop-timeout-seconds` |

## Example Usage

```terraform
resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Setting the restart-policy value for an app
resource "dokku_ps_property" "example" {
  app      = dokku_app.node_js_app.app
  property = "restart-policy"
  value    = "on-failure:5"
}

# Setting the restart-policy value globally
resource "dokku_ps_property" "example_2" {
  global   = true
  property = "restart-policy"
  value    = "on-failure:5"
}
```
