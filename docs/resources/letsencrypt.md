# dokku_letsencrypt (Resource)

Enables or disables letsencrypt SSL certificates for a dokku application

### Requirements

- Dokku >= 0.38.31
- dokku-letsencrypt plugin >= 0.25.2

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `present` and torn down with state `absent`. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "letsencrypt" {
  name = "letsencrypt"
  url  = "https://github.com/dokku/dokku-letsencrypt.git"
}

resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

resource "dokku_git_from_image" "node_js_app_git_from_image" {
  app   = dokku_app.node_js_app.app
  image = "dokku/smoke-test-app:dockerfile"
}

# Enable letsencrypt for an app
resource "dokku_letsencrypt" "example" {
  app        = dokku_app.node_js_app.app
  depends_on = [dokku_plugin.letsencrypt, dokku_git_from_image.node_js_app_git_from_image]
}
```
