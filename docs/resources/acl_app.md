# dokku_acl_app (Resource)

Manages the dokku-acl access list for a dokku application

### Requirements

- Dokku >= 0.38.31
- dokku-acl plugin >= 2.0.1

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `users`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app`. Manages the whole `users` collection; entries are identified by value.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

## Example Usage

```terraform
resource "dokku_plugin" "acl" {
  name = "acl"
  url  = "https://github.com/dokku-community/dokku-acl.git"
}

resource "dokku_app" "node_js_app" {
  app = "node-js-app"
}

# Grant users access to an app
resource "dokku_acl_app" "example" {
  app        = dokku_app.node_js_app.app
  users      = ["alice", "bob"]
  depends_on = [dokku_plugin.acl]
}
```
