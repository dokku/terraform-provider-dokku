# dokku_domains (Resource)

Manages the domains for a given dokku application or globally

### Requirements

- Dokku >= 0.38.31

### Export support

Supported.

### Probe support

Supported.

### Lifecycle

Applied with state `set` and torn down with state `clear`, which refuses `domains`, so a teardown resets it. See [Applying and tearing down a task](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#applying-and-tearing-down-a-task).

### Identity

Keyed by `app` and `global`. Fields left empty are omitted from the address. Manages the whole `domains` collection; entries are identified by value.

### Objects

- The app named by `app`.

Tasks applied at once on the same object take turns; see [Running tasks concurrently](https://github.com/dokku/docket/blob/v0.11.0/docs/embedding.md#running-tasks-concurrently).

### Constraints

- Exactly one of `app` or `global` must be set.

## Example Usage

```terraform
resource "dokku_app" "example_app" {
  app = "example-app"
}

# Add domains to an app
resource "dokku_domains" "example" {
  app     = dokku_app.example_app.app
  domains = ["example.com", "www.example.com"]
}

# Set global domains
resource "dokku_domains" "example_2" {
  global  = true
  domains = ["global.example.com"]
}
```
